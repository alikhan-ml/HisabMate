
# HisabMate

A web-based digital udhaar management system for small shopkeepers.

## Project Goals
- Manage customer profiles and contact details.
- Record credit given and payments received.
- Calculate pending balances automatically.
- Enter transactions using everyday Hindi/Hinglish.
- View transaction history and monthly statements.
