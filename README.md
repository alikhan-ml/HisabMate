# HisabMate Website Starter

A responsive frontend landing page for the HisabMate digital khata project.

## Design choices
- **Playfair Display** for warm, classic display headings.
- **DM Sans** for readable body text, navigation and buttons.
- Warm paper `#f7f1e7`, sage `#dce5d0`, forest green `#213f2c`.
- Uses your supplied background image at `assets/hisabmate-background.png`.

## Run
Open this folder in VS Code and open `index.html` in your browser. For live reload, use VS Code Live Server. Google Fonts need internet; fallback fonts are included.

## Current scope
This is frontend only. The button/menu interactions work, but there is no database or real customer data yet. Next build the dashboard screens and forms; after the frontend flow is ready, connect Flask and MySQL.
